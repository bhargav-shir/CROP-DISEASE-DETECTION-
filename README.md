# 🌱 Crop Disease Detection and Treatment Recommendation System

An application-based Machine Learning and Deep Learning project that uses plant leaf images to identify crop diseases and provide relevant treatment and prevention recommendations.

## 🎯 Project Overview

Crop diseases can significantly affect agricultural productivity. This project aims to help users perform preliminary crop disease identification using deep learning and access relevant disease management information through a simple web interface.

## ✨ Key Features

* 🌿 **Disease Detection:** Classifies supported crop diseases from leaf images.
* 🧠 **Deep Learning:** Uses CNN and MobileNetV2 architectures.
* 💊 **Treatment Recommendations:** Provides relevant treatment and prevention information from a knowledge base.
* 🖥️ **Web Application:** Interactive interface built with Streamlit.
* 📊 **Model Evaluation:** Evaluates classification performance and explores limitations on real-world images.

## 🛠️ Technologies Used

* Python
* TensorFlow
* Convolutional Neural Network (CNN)
* MobileNetV2
* PlantVillage Dataset
* PlantDoc Dataset for potential real-world validation
* Streamlit
* Git and GitHub

## ⚠️ Disclaimer

Predictions and recommendations are intended for preliminary informational purposes only. Model predictions may be inaccurate, particularly for images or diseases outside the supported dataset. Users should consult agricultural experts for reliable diagnosis and treatment decisions.
